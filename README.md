# Exemplos de HTML, CSS e Bootstrap

Conjunto de páginas com exemplos de estrutura HTML, navegação, formulários, tabelas, estilos e componentes do Bootstrap. A página inicial reúne links para parte dos exemplos; outros arquivos podem ser abertos diretamente.

## Conteúdo

- HTML semântico, links, listas, tabelas e formulários
- CSS em arquivo separado
- Layout e componentes com Bootstrap

## Como visualizar

Abra index.html em um navegador. Para acessar exemplos adicionais, abra os arquivos da pasta ex/.
